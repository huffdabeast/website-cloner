The Blueprint Datasheet

Skyfall's interface reads like an engineering drawing typeset for the screen: flat paper, 1px hairlines, mono annotations, enormous medium-weight headlines, and a single blue that carries every signal.

Read DESIGN.md Jump to components↗
  • 01 / Palette

    One accent on an achromatic ramp. Blue lifts to #6f83f0 on dark grounds.

  • 02 / Geometry

    Zero radius. Squares, brackets, hairlines and dotted fields are the only decoration.

  • 03 / Type

    Geist at weight 500 for reading; Geist Mono, small and uppercase, for every annotation.

  • 04 / Motion

    Scroll-gated, masked, expo-eased. Nothing bounces; reduced motion disables it all.

          The One Blue Rule

          Skyfall Blue is the only saturated colour in the UI. If a second accent seems necessary, the answer is a hairline, a mono label or more white space.

          The Lift Rule

          On ink or night grounds, blue text and hover states use Blue Lift #6f83f0, never the base blue, which fails contrast on #1a1a1a.

          The Tone Quarantine Rule

          Pixel tones live only inside pixel icons. They never appear in type, buttons or backgrounds.

          Typography

          Geist does the reading at medium weight with tight negative tracking, and Geist Mono does the annotating. Weight stays in the 400–600 band.

          The No-Shadow Rule

          Never add box-shadow. If something needs lifting, give it a 1px ink border, a title bar, or a field behind it. The only soft effect on the site is backdrop: rgb(26 26 26 / .4) with a 2px blur behind native dialogs.

          The Draw-It Rule. Depth is implied by brackets, dots and rules.

          Do's and don'ts

          Do

          • Keep Skyfall Blue to signal: current tab, hover, focus, selection, the active bar, dates, the / prefix.
          • Build groups as shared-border hairline grids (border-t border-l on the list, border-r border-b on cells).
          • Set every label, tag, meta line and button in Geist Mono, 11–15px, uppercase, −0.02em (or +0.05em at 11px).
          • Set headlines at weight 500, −0.045em tracking, line-height under 1, capitalised.
          • Switch section grounds (paper → studio → night → blue) to create rhythm.
          • Frame figures with a left ink rule, corner brackets, corner dots or a dotted field.
          • Ease everything out on the expo curve and gate reveals on scroll position.
          • Keep touch targets at 44px and focus rings at 2px blue with 2px offset.

          Don't

          • Don't add border radius to anything.
          • Don't add box shadows, surface gradients or glassmorphism; the dialog backdrop blur is the one exception.
          • Don't introduce a second accent or use pixel tones outside pixel icons.
          • Don't use the base blue for text on ink or night; use Blue Lift #6f83f0.
          • Don't set body copy in mono or labels in Geist.
          • Don't use weights above 600 or below 400.
          • Don't replace hairlines with spacing-only separation inside grids; the lines are the structure.
          • Don't bounce, overshoot or spring; motion decelerates and stops.
